# GlobalTech Solutions Customer Management System

## 📌 Overview

This project is a Python-based **Customer Management System** developed for GlobalTech Solutions. It demonstrates the use of **dictionaries, loops, functions, and basic data aggregation** to manage customers, services, and project data.

The program simulates real-world business operations such as:

* Customer data storage and retrieval
* Project tracking
* Cost calculations
* Service usage analysis
* Financial reporting
* Recommendation systems

---

## 🚀 Features

### 1. Service Management

* Stores service categories with hourly rates
* Supports dynamic rate adjustments (+10%)

### 2. Customer Management

* Maintains customer records using dictionaries
* Allows lookup, updates, and validation of customer data

### 3. Project Tracking

* Assigns projects to customers
* Tracks:

  * Project name
  * Service type
  * Hours worked
  * Budget

### 4. Cost Calculation

* Automatically calculates project costs using:

  ```
  cost = hourly_rate × hours
  ```

### 5. Data Analysis & Reporting

* Customer statistics (total customers, company names)
* Service usage frequency
* Financial summaries:

  * Total hours
  * Total budget
  * Average project budget
  * Highest & lowest budgets

### 6. Advanced Features

* Dictionary comprehensions for:

  * Rate adjustments
  * Active customers filtering
  * Budget summaries
  * Service tiers (Basic, Standard, Premium)

### 7. Validation System

* Ensures all customers have required fields:

  * Company name
  * Contact person
  * Email
  * Phone

### 8. Project Status Tracking

* Automatically assigns statuses:

  * Active
  * Completed
  * Pending

### 9. Budget Analysis

* Calculates per-customer:

  * Total budget
  * Average budget
  * Number of projects

### 10. Service Recommendation System

* Suggests services based on:

  * Previous usage
  * Customer budget
